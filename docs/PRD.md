# TFWatch 产品需求

TFWatch 自托管监控 Apple TestFlight 公开邀请。访客可搜索公共软件库并查看状态和开放时间线。用户可注册、登录、重置或修改密码，提交链接，管理关注和独立通知设置。管理员管理账号、库内项目、检测频率、注册与匿名浏览开关。

- 邀请按大小写敏感的邀请码去重。一个软件可关联多个邀请。关注按邀请管理，取消关注不删除邀请。
- 邮件（已验证收件地址）、Telegram、ntfy 和 HTTPS Webhook 可分别启用及测试。触发条件为「仅开放」或「所有可辨识的状态变化」。
- 时间线支持最近 7 / 30 / 90 天和全部历史。显示检测状态、最近检测开放、观察到的开放次数与时长估计。未知和采样中断需显式呈现。
- 交付 Vue 3 + FastAPI、SQLite / PostgreSQL、Docker Compose / Linux systemd、AGPL-3.0-only。

## 实施阶段

1. 工程骨架、数据库与认证。
2. 共享目录、监控、搜索、统计与时间线。
3. 关注、账号管理、通知及管理后台。
4. 前端集成、部署与发布检查。每阶段运行对应测试。
